# Day 3 — OSI Model
**Planned date:** 2026-08-26

| Layer | Name | Work / example |
|---|---|---|
| L7 | Application | HTTP / HTTPS |
| L6 | Presentation | Data format, encryption/encoding, compression |
| L5 | Session | Establish/manage/terminate sessions |
| L4 | Transport | End-to-end delivery, reliability, ports |
| L3 | Network | IP, subnetting, routing |
| L2 | Data Link | Ethernet, switches, MAC |
| L1 | Physical | Bits over electrical/optical/radio signals |

## Memory
L7 Application → L6 Presentation → L5 Session → L4 Transport → L3 Network → L2 Data Link → L1 Physical.
