# Day 4 — TCP/IP vs OSI
**Planned date:** 2026-08-27

## TCP/IP model
1. Application
2. Transport
3. Internet
4. Network Access

## Mapping

| TCP/IP | OSI |
|---|---|
| Application | Application + Presentation + Session |
| Transport | Transport |
| Internet | Network |
| Network Access | Data Link + Physical |

## Simplified example
HTTPS → TCP/443 → IP → Ethernet/Wi-Fi → physical signals.
