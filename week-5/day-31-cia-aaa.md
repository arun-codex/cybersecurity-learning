# Day 31 — Security Fundamentals: CIA Triad + AAA
**Planned date:** 2026-09-23

## CIA
- **Confidentiality** — only authorized people can access information.
- **Integrity** — information should not be modified improperly.
- **Availability** — systems/data should be accessible when needed.

Memory:
```text
Confidentiality → SEE
Integrity → CHANGE
Availability → USE
```

## AAA
- Authentication → Who are you?
- Authorization → What are you allowed to do?
- Accounting → What did you do?

## SOC connection
Authentication → permission check → activity recorded in logs.

Logs are important telemetry for SOC investigations.
