# Day 32 — Least Privilege + Defense in Depth
**Planned date:** 2026-09-24

## Least privilege
Give a user/process only the permissions required to perform its job.

## Defense in depth
Use multiple security layers so one failed control does not mean total compromise.

Example layers:
- Firewall
- Authentication
- Permissions
- Endpoint security
- Logging
- Backups

## Linux connection
```bash
whoami
id
ls -l
```

## Key idea
Security should not depend on a single control.
