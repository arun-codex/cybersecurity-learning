# Day 11 — HTTP Fundamentals
**Planned date:** 2026-09-03

## Flow
Browser → HTTP request → Web server → HTTP response → Browser

## Methods
GET, POST, PUT, PATCH, DELETE

## Status codes
200 OK · 201 Created · 301 Permanent redirect · 302 Temporary redirect · 400 Bad request · 401 Auth required · 403 Forbidden · 404 Not found · 500 Server error

## SOC interpretation
Inspect the URL, method, status, headers, timing, source and destination.
