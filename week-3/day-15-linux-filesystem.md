# Day 15 — Linux Filesystem + Navigation
**Planned date:** 2026-09-07

## Directories
- `/` → root of filesystem
- `/home` → normal users' home directories
- `/etc` → system/application configuration
- `/var` → changing data such as logs/caches
- `/root` → root user's home
- `/tmp` → temporary files

## Commands
```bash
pwd
ls
ls -la
cd /
cd /home
cd /etc
cd /var
cd ~
```

## SOC connection
`/etc` and `/var` are important areas during system investigation.
